# 河南省交通大数据 - 实时数据流程验证命令

## 数据流程架构
```
MySQL基础表 → Maxwell(CDC) → Kafka → Flink消费计算 → Redis → Spring Boot Service → 前端轮询
```

---

## 1. MySQL 基础表验证

### 1.1 查看基础表数据
```bash
# 登录MySQL
mysql -uroot -p000000 -h hadoop102

USE traffic_sql;

SELECT * FROM traffic_flow LIMIT 5;
```

## 2. Maxwell CDC 验证

### 2.1 检查Maxwell状态
```bash
# 查看Maxwell进程
ps -ef | grep maxwell

# 查看Maxwell日志
tail -f /opt/module/maxwell/logs/maxwell.log
```

**预期日志输出：**
```
INFO  BinlogConnectorReplicator - Binlog connected.
INFO  Maxwell - Maxwell is starting
```

### 2.2 启动Maxwell（如未运行）
```bash
cd /opt/module/maxwell
bin/maxwell --config config.properties --daemon
```

### 2.3 检查Maxwell配置
```bash
cat /opt/module/maxwell/config.properties
```

**关键配置项：**
```properties
producer=kafka
kafka.bootstrap.servers=hadoop102:9092
kafka_topic=maxwell
filter=include:traffic_sql.traffic_flow,include:traffic_sql.vehicle_traffic,include:traffic_sql.traffic_violation,...
```



**预期看到：**

- Job Name: Traffic Realtime Compute Job

### 4.3 查看Flink日志
```bash
tail -f /opt/module/flink-1.17.1/log/flink-*-taskexecutor-*.log
```

```bash
bin/flink run -d /opt/module/flink/jobs/traffic-flink-job-1.0.0.jar
```

## 8. 完整数据流测试

### 8.1 一键测试脚本
```bash
#!/bin/bash
# 保存为 test_data_flow.sh

echo "=== 1. 更新MySQL数据 ==="
mysql -uroot -p000000 -h hadoop102 -e "USE traffic_sql; UPDATE traffic_flow SET flow_count = flow_count + 1000 WHERE flow_id = 1;"
echo "MySQL更新完成"

sleep 2

echo "=== 2. 检查Kafka消息 ==="
timeout 5 kafka-console-consumer.sh --bootstrap-server hadoop102:9092 --topic maxwell --from-beginning 2>/dev/null | tail -1
echo ""

sleep 3

echo "=== 3. 检查Redis数据 ==="
redis-cli -h hadoop102 -p 6379 HGET traffic:traffic_flow "14_1"
echo ""

echo "=== 4. 检查API返回 ==="
curl -s http://localhost:8080/api/realtime/traffic-flow | head -c 200
echo ""

echo "=== 测试完成 ==="
```

### 8.2 执行测试
```bash
chmod +x test_data_flow.sh
./test_data_flow.sh
```

## 9. 常见问题排查

### 9.1 Maxwell未捕获数据
```bash
# 检查MySQL binlog是否开启
mysql -uroot -p000000 -e "SHOW VARIABLES LIKE 'log_bin';"
# 预期: log_bin = ON

# 检查Maxwell filter配置
cat /opt/module/maxwell/config.properties | grep filter
```

### 9.2 Kafka无消息
```bash
# 检查Kafka是否运行
jps | grep Kafka

# 检查Topic是否存在
kafka-topics.sh --bootstrap-server hadoop102:9092 --list
```

### 9.3 Redis无数据
```bash
# 检查Flink任务是否运行
cd /opt/module/flink-1.17.1 && bin/flink list

# 检查Flink日志错误
tail -100 /opt/module/flink-1.17.1/log/flink-*-taskexecutor-*.log | grep -i error
```

### 9.4 API返回空数据
```bash
# 检查Spring Boot是否连接Redis
curl http://localhost:8080/api/realtime/status

# 检查Redis连接配置
cat src/main/resources/application.yml | grep redis
```
